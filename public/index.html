The tape · drum rotations
Every figure here is a converted count, derived from a raw count. Both REDCap projects are read on one basis — converted count = raw count × the network conversion factor — so a day from the archive and a day from the prospective grid sit on the same scale. The converted count stored in REDCap is deliberately not used: it is rounded to a whole number per row, and rounding many rows before summing accumulates error worst at the low counts that set season start and end dates. Values are carried unrounded and rounded only for display. Gaps are shown as gaps: a day with no valid sample is excluded from means and marked, never read as zero.
Risk bands are placeholders and must be set by the network's clinical advisory group before public release. Season descriptors use the 95% cumulative method (2.5% to 97.5% of the annual integral).
