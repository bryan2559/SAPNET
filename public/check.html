Reading the result

  • An asset shows FAIL 404 — that file is not in the deployed build. Check Netlify is building from the folder containing netlify.toml, then redeploy with Clear cache and deploy site.
  • “Dashboard module runs” shows FAIL — the dashboard's code never executes, which is what leaves it on its loading spinner. The data timeouts live inside that module and cannot help. The browser console names the file and the reason.
  • /api/health shows FAIL 404 — the serverless functions are not deployed, so the data endpoint cannot work either.
  • /api/health passes but /api/observations times out — the code is fine and the REDCap export is too slow. Narrow it with REDCAP_FILTER_<KEY> or publish a snapshot.
  • Everything passes — the dashboard should load. If it still does not, the browser is holding a stale cached page: hard-refresh.
